隐私政策

生效日期：2026-08-07 · Effective date: August 7, 2026

中文在前，English version below ↓

简体中文

一句话总结：书签管理器 Pro（下称"本扩展"）是一个本地优先工具。开发者没有后端服务器、账号系统或分析服务；唯一的外部请求是生成网页预览截图（可一键关闭），以及你主动点击"检测失效链接"时的检测请求。

1. 本地保存的数据

开发者不收集这些数据。本扩展没有后端服务器，开发者无法读取以下仅保存在你自己浏览器本地存储（chrome.storage.local）中的信息：

  • 你手动设置的书签分类；
  • 打开书签的次数与时间（用于"常用书签"排序）；
  • 界面偏好：主题、显示密度、排序方式、网页预览开关、新标签页接管开关。

书签本身由 Chrome 浏览器管理，本扩展只是读取和（在你操作时）修改它们。卸载本扩展后，上述本地数据会被 Chrome 自动清除，你的书签不受影响。

2. 权限用途逐项说明

权限用途
bookmarks读取和管理你的 Chrome 书签——这是本扩展的核心功能（展示、搜索、移动、编辑、删除、排序）。
storage在本地保存你的分类、书签打开次数和界面偏好（见第 1 条）。
favicon从 Chrome 本地的图标缓存读取网站图标用于展示，零网络请求。
history读取最近 30 天的访问次数，用于"常用书签"排序——这样不论你从 Chrome 书签栏、地址栏还是本扩展打开书签，都会计入。查询在你本机完成，只用于给你自己的书签排序，不存储、不上传、不发送到任何服务器（本扩展没有服务器）。
s0.wp.com获取网页预览截图（见第 3 条），可在导航页顶栏一键关闭。
chrome_url_overrides（新标签页）把新标签页替换为书签导航页，默认开启，可在导航页顶栏一键关闭（关闭后新标签页显示 Google 首页）。
可选：所有网站仅当你主动点击"检测失效链接"时申请，用于逐个访问当前范围内的书签网址。不点击该功能，此权限不会被申请。

3. 第三方服务：网页预览截图

网页预览默认开启。当书签卡片接近可视区域时，对应书签网址会发送给 WordPress.com 的公开截图服务 mShots（域名 s0.wp.com，由 Automattic 运营）以生成截图；结果缓存在你的浏览器本地。该服务受 Automattic 隐私政策约束。

如果你不希望发送任何书签网址：在导航页顶栏点击「预览：开」把它切换为「预览：关」即可完全停用，卡片变为纯文字。之后只有你另行主动启动"检测失效链接"时，扩展才会访问书签网址。

4. 我们不做的事

  • 开发者不接收、不出售、不共享你的书签、分类或点击记录；
  • 不接入任何统计 / 分析 / 广告 SDK；
  • 不要求注册账号，不设置任何跟踪标识；
  • 不会将 Chrome API 数据用于广告、信用评估或与核心功能无关的用途。

本扩展对从 Chrome API 获得的信息的使用遵守 Chrome 网上应用店用户数据政策，包括 Limited Use（有限使用）要求。

5. 数据删除

卸载本扩展即删除其全部本地数据（Chrome 自动完成）。你的书签是 Chrome 的数据，不会因卸载本扩展而改变。

6. 政策变更与联系方式

如本政策有实质性变更，我们会在扩展更新说明和本页面中注明。任何疑问请联系：allenma2ong@gmail.com

ENGLISH

In one sentence: Bookmark Manager Pro ("the Extension") is local-first. The developer has no backend, account system, or analytics service. The only external requests are preview screenshots (which you can switch off with one click) and the checks you start yourself with "Check dead links".

1. Data stored locally

The developer does not collect this data. The Extension has no backend, so the developer cannot access the following information stored only in your browser's local storage (chrome.storage.local):

  • Categories you assign to bookmarks manually;
  • How often and when you open your bookmarks (powers "Frequent" sorting);
  • Interface preferences: theme, display density, sort order, preview on/off, new-tab takeover on/off.

Your bookmarks themselves are managed by Chrome; the Extension only reads them and modifies them when you act. Uninstalling the Extension removes all of the local data above (handled by Chrome); your bookmarks are unaffected.

2. Permissions, one by one

PermissionWhy it's needed
bookmarksRead and manage your Chrome bookmarks — the core purpose of the Extension (display, search, move, edit, delete, reorder).
storageSave categories, bookmark open counts, and preferences locally (see section 1).
faviconShow site icons from Chrome's local favicon cache — zero network requests.
historyRead visit counts from the last 30 days to rank "Frequent" bookmarks — so opens from Chrome's bookmarks bar, the address bar, or this extension all count. The query runs locally on your machine and is used only to sort your own bookmarks: nothing is stored, uploaded, or sent to any server (the Extension has no server).
s0.wp.comFetch preview screenshots (see section 3); switchable off in the grid header.
chrome_url_overrides (new tab)Replace the new tab page with the bookmark navigation page. On by default; one click in the grid header turns it off (new tabs then open the Google homepage).
Optional: all sitesRequested only when you click "Check dead links", so the Extension can request each bookmarked URL to verify it still works. If you never use that feature, this permission is never requested.

3. Third-party service: preview screenshots

Page previews are on by default. As a bookmark card approaches the visible area, its URL is sent to WordPress.com's public mShots screenshot service (s0.wp.com, operated by Automattic) to generate the screenshot; the result is cached locally in your browser. The service is governed by Automattic's privacy policy.

If you'd rather send no bookmark URLs at all, click "Preview: On" in the grid header to switch it to "Preview: Off" — screenshot requests stop entirely and cards become text-only. The Extension will then contact bookmarked sites only if you separately start a dead-link scan.

4. What we never do

  • The developer does not receive, sell, or share your bookmarks, categories, or click records;
  • No analytics, telemetry, or advertising SDKs;
  • No accounts or tracking identifiers;
  • No use of Chrome API data for advertising, credit assessment, or purposes unrelated to the Extension's core features.

The Extension's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

5. Data deletion

Uninstalling the Extension deletes all of its local data (Chrome handles this automatically). Your bookmarks belong to Chrome and are not affected.

6. Changes & contact

Material changes to this policy will be noted in the extension's release notes and on this page. Questions: allenma2ong@gmail.com
